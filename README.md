# 踢坏人 · 整蛊小游戏

第三人称的网页小游戏：走进一间客厅，用脚踹两个坏人，踹到他们跪地求饶、掏钱赔罪。
卡通夸张演出，没有血腥画面。**只适合朋友之间开玩笑，请先征得当事人同意，别拿去网暴别人。**

双击 `index.html` 就能玩，不需要安装任何东西（three.js 从 CDN 现拉，三个源自动回退）。

## 这份代码里已经抹掉的东西

- **照片**：三张真人照片的 Base64 不提交（`faces/` 已写进 .gitignore）。拉下来直接打开能跑，只是脸上是程序画的底脸，角色面板和收款弹窗那两个圆头像会是空的。
- **姓名**：三位演员在原作里是真人姓名，这份公开代码统一换成了 `坏人A` / `坏人B` / `主角` 占位（代码里 `CAST`、`HERO_NAME` 和界面文案都同步改掉，功能不受影响）。你拿到自己的照片和名单后按下面的方法填回去即可。

想把某段逻辑改回真名，全局搜索 `坏人A` / `坏人B` / `主角` 三个词就行，一共不到二十处，都在数据表和文案里。

## 怎么填回照片

1. 把三张照片分别转成 data URI，存成 `faces/a.txt`（站左边那个坏人）、`faces/b.txt`（站右边的坏人）、`faces/c.txt`（主角）；
2. 跑一次 `node build-faces.mjs`，脚本会把这三行塞进 `index.html` 的 `const FACES = { ... };` 块里；
3. 脚本是幂等的，换图重跑就行，别手改那一行。

## 怎么玩

| | 电脑 | 手机 |
| --- | --- | --- |
| 移动 | `W A S D` 走位，`Shift` 冲刺 | 左下拇指区一按就浮出摇杆（不用瞄准那个圈） |
| 出脚 | 鼠标左键正踹 / 右键回旋踢，`空格 / J · K` 是键盘党备用键 | 右下角两个按钮「踹！」「回旋」 |
| 转视角 | 点一下画面接管鼠标，移动鼠标即转镜头，`Esc` 松开去点顶部按钮 | 其余屏幕按住拖动转镜头，双指缩放 |
| 其他 | `F` 怼脸特写，滚轮拉近拉远 | 推摇杆时镜头会慢慢转到你面朝的正面 |

浏览器不允许隐藏光标时，电脑端会自动退回"按住拖动转视角、点一下出脚"。竖屏手机会自动放宽视角（`baseFov` / `distBias`），不然坏人会被怼成一整张脸。

## 代码怎么读（按顺序看下来最快）

整份逻辑都在 `index.html` 的 `<script type="module">` 里，约 2750 行（照片注入后约 400 KB），从上到下分成这几段：

1. **房间和演员表**：`ROOM`（`W/D/H/x0/z0`，所有墙、门、家具尺寸都从它推）、`GOON_TYPES`（两种坏人的称呼和嘴硬台词）、`CAST`（坏人A 在屏幕左边、坏人B 在右边，名字、身高、初始站位、照片裁切参数 `crop` 都写死在这里）。
2. **骨架与姿势**：`makeHumanoid()` 拼出身体各段，`basePose / P() / blendPose / applyPose` 是姿势系统。骨头默认朝 `-Y`，所以 `rx` 为负是把胳膊往前往上抡；膝盖方向相反（正值是往后折），手肘也是负的（`basePose` 里 `elL/elR.rx = -.25`）——这一条符号错了整个人就成反关节。
3. **玩家与镜头**：`updatePlayer()` 把键盘/摇杆输入换成 `dir = atan2(-ix, iy) + camYaw - camAuto`；`updateCamera()` 负责跟随，手机推摇杆时让它慢慢转到面朝的正面，`camAuto` 专门把"镜头自动回正"和"走位基准"解耦，不然会正反馈原地绕圈。
4. **输入**：`keys` + `touch` + `pointerdown/move/up`，桌面端另有一层 pointer lock（`lockMouse` / `locked` / `lockFails`，失败两次自动退回拖动）。
5. **踹人链**：`tryKick()` 出脚 → `hurtPose` 抱头乱窜（跑动中 `spawnBill` 掉钱）→ 血量见底 `fallPose` 倒地 → `kneelPose` 跪地 → `payPose` + `beginPay / updatePay / showPay` 弹收款框并 `player.ko++` → `fleePose` 跑开后 `removeEnemy` 把它移出数组（所以 `enemies[1]` 可能是 `undefined`，取值前都得防一下）。坏人不会反击，也不会追着玩家跑，只会求饶和递钱。
6. **贴图**：`fitFaceImage()` 按 `crop` 抠正脸（坏人B 那条是 `crop: false`，整张等比塞进去），`setFaceTexture()` 贴到 3D 脸上，`applyCastFaces()` 顺手刷新角色面板的圆头像。
7. **调试钩子**：末尾的 `window.__dbg`（`spawnEnemy / tryKick / freeze / step / shot / camState / lookBy` 等）是给开发期在浏览器控制台直接驱动游戏用的，正常玩不会碰到。
